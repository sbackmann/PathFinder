# PathFinder

The `pathfinder` library is a prompting library, that wraps around the most common LLM inference backends (OpenAI, Azure OpenAI, Anthropic, Mistral, OpenRouter, `transformers` library and `vllm`) and allows for easy inference with LLMs.

This is an adapted version of Giorgio Piatti's [pathfinder](https://github.com/giorgiopiatti/PathFinder) library.
